    元の実装が「音側を戻さない」方針だったのはこのため。
  - 曲トラックを**ドラッグでスクラブ**できるようにした。ドラッグ中は再生ヘッドと曲の音だけを
    動かし、映像のシークは離してから 1 回だけ（クリップの読み込みが重いため）。
  - **停止中はスクラブ位置の曲を鳴らす**（Resolve の挙動）。再生用の `<audio>` は App が持って
    いて再生状態と結びついているため、スクラブ専用の `<audio>` を音楽ビュー側に別途持たせた。
- [x] **ドラッグを離すと一瞬元の形へ戻ってから変わる問題を修正**（2026-08-16）:
  保存 → グラフ再読み込みが返るまで `nodes` は古い値のままなので、`setDrag(null)` した瞬間に
  古い状態で 1 フレーム描かれていた。**保存した配置を `pending` として控え、反映が届くまで
  そちらを優先して描く**ようにした（届いたら捨てる）。
  - **反映判定は 3 つの値すべてを突き合わせること**（`start_sec` / `dur_sec` / `src_offset`）。
    開始位置だけを見ていると、**尺や使用開始位置だけを変えたときに「元から一致している」と
    誤判定して控えを先に捨ててしまう**（位置の移動では直って見えるが、尺の変更では直らない）。
    最初この誤りを踏んだ。
  - 保存に失敗したときは控えを捨てて、保存済みの状態を正として描き直す。
- [x] **音楽タイムラインを秒ベースに変更、拍グリッドを廃止**（2026-08-15）:
  拍が取れない曲・検出を誤る曲では**誤ったグリッドがかえって編集の邪魔になる**ため、
  「拍が正確に取れること」を前提にした設計をやめた。「曲に映像を合わせる」編集スタイルは
  そのまま残し、**波形と時間ルーラーの上で秒で尺を決める**形にした。
  - **消したもの**: テンポ倍率 / 拍子 / 小節頭のセレクタ、メトロノーム、小節線・小節番号、
    曲差し替え時の自動縮小（`autoShrinkForBeat` / `auto_shrunk` / `updateSequenceNodeMusicMany`）、
    `beats.ts` のテンポ倍率まわり。
  - **DB**: `sequence_nodes.units`(拍数) → `dur_sec`(秒)。`auto_shrunk` と
    `sequence_bgm.{beats_per_bar, bar_phase, tempo_ratio}` は `ALTER TABLE ... DROP COLUMN` で削除。
    拍数から秒への正確な変換手段が無い（テンポ自体を捨てるため）ので、**旧 units は変換せず捨てた**
    （ユーザー合意済み）。各クリップは「元の区間の残り全部」から始まる。
  - **UI**: 小節線 → 時間ルーラー（主目盛りに `m:ss`）。吸着は
    `なし / 0.1 / 0.25 / 0.5 / 1 / 2 / 5 秒`（既定 0.5 秒、`localStorage` のキーも `snapSec` へ）。
    尺は最小 0.1 秒、最大は元の区間の残りで頭打ち。スリップ（Alt ドラッグ）は吸着させない。
  - **残したもの**: `beats.ts` と `bgm:analyzeBeats` は BGM プレイヤーの BPM 表示 /
    メトロノーム / タップテンポで引き続き使う（表示専用で編集を駆動しない）。
  - **失ったもの**: 「曲を差し替えると全クリップが自動で並び直る」。尺が秒になったので合わせ直しは手作業。
  - 拍検出まわりの調査結果（`Green From Above 2` の 2/3 ズレ、テンポ揺れへの頑健性、代表 BPM の
    量子化バグと修正）は plan.md の Phase 2.6c「検証結果 2 / 3」に残してある。

  **上下 10% を落とした平均**に変更した。拍間隔は整数フレームなので、中央値だと 150 BPM 付近で

- 開発 Tips:
  - **`ELECTRON_RUN_AS_NODE` を環境に残さないこと**。残っていると `electron .` が Node として起動し `require('electron')` がパス文字列を返してメイン処理がクラッシュする（起動時に `protocol` undefined になる）。
  - better-sqlite3 は Electron ABI プレビルドを [.npmrc](../../.npmrc) で取得。electron のメジャー更新時は `target` を合わせる。
