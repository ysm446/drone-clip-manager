### 2026-08-15 07:30
- **不具合修正**: 音楽タイムラインをクリックしたとき、**再生ヘッドが小節線からずれて止まる**問題を修正。
  拍への吸着自体は正しく効いていたが、直後に「動画が実際にシークした位置」でヘッドが
  上書きされていた。動画のシークは要求位置ちょうどには着地しない（実測で 76〜360ms 後ろ）ため、

  - あわせて、**ズームを変えたときにヘッドが追従しない**（古い位置に取り残される）問題と、
    **曲を差し替えた直後に前の曲の小節線が残る**問題も修正した。

### 2026-08-15 01:30
- **音楽ビューで、映像と曲を一緒に再生できるようにした**。ヘッダの「再生」で、
  タイムラインで決めた長さのまま順路を再生しつつ、**曲も同時に鳴る**。
  書き出す前にカットが拍に乗っているかを耳で確認できる。
  - **音は途切れさせない**方針。クリップの読み込みで間が空いたぶんは、次のクリップの頭を
    その分だけ飛ばして**映像側を音に合わせる**（音が止まると拍の判断ができなくなるため）。
  - ループ再生を ON にしていると、曲も使い始め位置へ巻き戻る。
- **クリップの尺を吸着させる単位を選べるようにした**。ヘッダの「吸着」で
  **1拍 / 2拍 / 1小節 / 2小節 / 4小節** から選ぶ。設定は記憶する（既定は 1小節）。
  - 尺は選んだ単位の**整数倍なら何でも可**になった。1小節を選べば 3小節・5小節・7小節も作れる。
    従来の固定候補（1・2・3・4・6・8小節）より自由に決められる。

### 2026-08-15 00:40
- **音楽ビューから、拍に合わせた 1 本の動画を書き出せるようにした**（Phase 2.6c 段階 4）。
  音楽ビューの「書き出し…」を押すと、**タイムラインで決めた長さのまま無劣化（stream copy）で
  連結し、BGM を載せて 1 本**に書き出す。**カットは曲の拍の上に乗る**。
  - **BGM の合成に対応**（Phase 2.6b）。映像は無劣化のまま、音声だけ BGM で上書きする。
    **フェードイン / フェードアウト**の秒数を指定できる（既定 1 秒 / 2 秒）。
    曲がシーケンスより短ければ無音で終わり、長ければ末尾で切る。
  - 曲の**使い始め位置**（イントロ飛ばし）も書き出しに反映される。
  - 既存の「連結書き出し」「分割書き出し」の動作は**これまでと変わらない**。
    音楽ビューの書き出しだけが拍に合わせた長さになる。
  - 実素材での確認: 8 クリップ / 44 秒で**カットのズレは最大 7.7ms**（1 フレーム = 16.7ms）。
    クリップ数が増えてもズレは積み上がらない。映像は元と同じコーデック・解像度・fps のまま。

### 2026-08-14 22:40
- **音楽ビューでクリップの尺を編集できるようにした**（Phase 2.6c 段階 3a）。
  - **クリップの右端をドラッグ**すると尺が変わる。1拍 / 2拍 / 1・2・3・4・6・8小節に吸着するので、
    **カットは必ず拍の上に乗る**。
  - **Alt を押しながらドラッグ**すると、元の区間の**どこを使うか**を前後にずらせる

  - 尺は「秒」ではなく「何小節か」で記録する。そのため**曲を差し替えると全クリップが

  - **曲を差し替えて尺が入らなくなったクリップは、収まる最大の単位まで自動で縮める**。
    そのままだと以降のカットが全部ビートからずれてしまうため。縮めたクリップは
    警告色の枠と ⚠ で示し、件数をステータスバーに出す。
  - 手で伸ばして素材が足りなくなったクリップは、危険色の枠で示す。

### 2026-08-14 18:22
- **BGM のビート（拍・小節）を自動検出し、BGM プレイヤーに表示するようにした**（Phase 2.6c 段階 1）。
  曲を選ぶと自動で解析し、**BPM / 拍子 / 再生中の「小節.拍」** を表示する。
  再生中は拍に合わせてインジケータが点灯し、**小節頭だけキーカラー**になる。
  - 解析は `ffmpeg` でデコードするだけで、あとはアプリ内で完結する（追加インストール不要）。
    3 分の曲で 0.5〜1.5 秒。結果は `.dcm/beats/` にキャッシュするので 2 回目以降は待ち時間なし。
  - **テンポが一定でない曲にも追従する**。曲によっては演奏中にテンポが 1〜4 BPM 流れるため、
    一定テンポの曲は等間隔のグリッド、流れる曲は拍ごとに追従する方式へ自動で切り替える。
  - **拍スナップに向かない曲は警告を出す**（テンポの変動が大きい曲、明確な拍が無い環境音系）。
  - **TAP ボタン**で拍に合わせて叩くと、その BPM を手動で指定できる。「自動」で戻せる。
- **書き出したクリップが DaVinci Resolve 等で「元の尺のまま・該当部分以外は真っ黒」に
  なる不具合を修正**。DJI 機の MP4 に埋め込まれたサムネイル（PTS=0 の静止画ストリーム）も
  一緒にコピーしていたため、本編のタイムスタンプがゼロ基準に戻されず、MP4 に in 点ぶんの
  空の edit list が書かれていた。切り出し対象を本編映像 + 音声だけに限定して解消。
  分割書き出し・単体書き出し・連結書き出しのすべてに適用。
  - 修正前に書き出したファイルは直らないので、書き出し直しが必要。

### 2026-08-12 17:07
- **シーケンス画面に「分割書き出し…」を追加**。順路のクリップを 1 本に連結せず、
  **1 クリップ = 1 ファイル**で無劣化（stream copy）書き出しする。並び順は順路どおりで、
  ファイル名は連番になる。
  - 命名テンプレートに **`{index:000}`（ゼロ埋め連番。0 の数が桁数 → `001`, `002`…）** と
    **`{seq}`（シーケンス名）** を追加。既存の `{filename}` / `{label}` / `{index}` はそのまま。
  - 分割書き出しの既定テンプレートは `{seq}_{index:000}`（例: `朝の湖_001.mp4`）。
    テンプレートはクリップ画面の書き出しとは別枠で記憶するので、互いに影響しない。
  - **書き出し先にシーケンス名のフォルダを作る**チェックボックス（既定 ON）。
    複数シーケンスを同じ書き出し先へ出しても混ざらない。設定は記憶する。
